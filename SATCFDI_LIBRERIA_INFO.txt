4. PROCEDIMIENTO PARA ACTUALIZAR LA LIBRERIA SATCFDI
================================================================================

Cuando sea necesario actualizar la libreria satcfdi a una version mas reciente,
siga estos pasos:


PASO 1: REVISAR CAMBIOS Y COMPATIBILIDAD
-----------------------------------------
Antes de actualizar, consulte:
- Notas de lanzamiento en el repositorio oficial de satcfdi
- Cambios en la API que puedan afectar el codigo existente
- Nuevas dependencias requeridas
- Cambios en los catalogos del SAT


PASO 2: CREAR RESPALDO
-----------------------
Haga una copia de seguridad completa del proyecto antes de actualizar:
- Hacer commit de todos los cambios actuales en git
- Crear una rama de respaldo
- Documentar la version actual de satcfdi


PASO 3: ACTUALIZAR EN ENTORNO VIRTUAL
--------------------------------------
Activar el entorno virtual y actualizar la libreria:

Comando en PowerShell:
> & C:\Users\Abitt\Desktop\DespliegueV2\DocuSeal-main\venv\Scripts\Activate.ps1
> pip install --upgrade satcfdi

O para instalar una version especifica:
> pip install satcfdi==X.X.X

Verificar la version instalada:
> pip show satcfdi


PASO 4: ACTUALIZAR requirements.txt
------------------------------------
Edite el archivo requirements.txt en la raiz del proyecto:

Cambiar:
satcfdi>=4.8.1

Por la nueva version, ejemplo:
satcfdi>=5.0.0


PASO 5: PRUEBAS DE FUNCIONALIDAD
---------------------------------
Ejecute pruebas completas de todas las funcionalidades que usan satcfdi:

1. Sellado de XML
   - Probar con diferentes tipos de comprobantes
   - Verificar certificados y firmas digitales

2. Timbrado
   - Probar conexion con PAC
   - Verificar respuestas de timbrado
   - Validar XML timbrado

3. Cancelacion
   - Probar proceso de cancelacion
   - Verificar acuses de cancelacion

4. Conversion JSON a XML
   - Probar con diferentes estructuras
   - Validar complementos (Pago, Carta Porte)

5. Generacion de PDF
   - Verificar renderizado correcto
   - Validar plantillas HTML

6. Consulta de estatus
   - Probar servicios del SAT
   - Verificar respuestas de validacion


PASO 6: VERIFICAR ARCHIVOS DE DATOS
------------------------------------
Revise si hay nuevos archivos de datos requeridos:

1. Catalogos del SAT
   - Verificar ruta: venv/Lib/site-packages/satcfdi/catalogs/
   - Actualizar en DocuSealService.spec si es necesario

2. Esquemas XSD
   - Verificar ruta: venv/Lib/site-packages/satcfdi/transform/schemas/
   - Actualizar en DocuSealService.spec si es necesario

3. Templates de renderizado
   - Verificar ruta: venv/Lib/site-packages/satcfdi/render/
   - Actualizar en DocuSealService.spec si es necesario


PASO 7: ACTUALIZAR PYINSTALLER SPEC
------------------------------------
Si hay cambios en la estructura de modulos de satcfdi:

1. Revisar nuevos submodulos en hiddenimports
2. Agregar nuevas rutas de datos en datas
3. Verificar que no haya modulos deprecados


PASO 8: COMPILAR Y PROBAR EJECUTABLE
-------------------------------------
Genere el ejecutable y pruebe su funcionamiento:

Comando en PowerShell:
> cd C:\Users\Abitt\Desktop\DespliegueV2\DocuSeal-main
> pyinstaller DocuSealService.spec

Pruebe el ejecutable generado en build/DocuSealService/:
- Ejecutar el servicio
- Probar todas las funcionalidades criticas
- Verificar logs de errores


PASO 9: REVISAR DEPENDENCIAS
-----------------------------
satcfdi puede tener sus propias dependencias que tambien deben actualizarse:

- cryptography: Usada para manejo de certificados
- lxml: Usada para procesamiento XML
- requests: Usada para comunicacion con PACs

Verificar compatibilidad de versiones:
> pip list

5. PROBLEMAS COMUNES Y SOLUCIONES
================================================================================

PROBLEMA 1: Error al importar satcfdi
--------------------------------------
Error: ModuleNotFoundError: No module named 'satcfdi'

Solucion:
- Verificar que el entorno virtual este activado
- Reinstalar: pip install satcfdi>=4.8.1
- Verificar el archivo requirements.txt


PROBLEMA 2: Error con certificados
-----------------------------------
Error: Error al cargar certificado o llave privada

Solucion:
- Verificar que los archivos CER y KEY esten correctamente codificados
- Validar que la contrasena del certificado sea correcta
- Verificar permisos de lectura de archivos


PROBLEMA 3: Catalogos no encontrados
-------------------------------------
Error: FileNotFoundError: catalogos no encontrados

Solucion:
- Verificar rutas en DocuSealService.spec
- Copiar manualmente catalogos desde venv/Lib/site-packages/satcfdi/catalogs
- Reconstruir el ejecutable con pyinstaller


PROBLEMA 4: Error en renderizado PDF
-------------------------------------
Error: Templates de renderizado no encontrados

Solucion:
- Verificar que satcfdi/render este incluido en datas del spec
- Verificar instalacion de pdfkit y wkhtmltopdf
- Revisar logs para identificar template faltante


PROBLEMA 5: Error de conexion con PAC
--------------------------------------
Error: Timeout o error de conexion con el PAC

Solucion:
- Verificar credenciales del PAC
- Validar configuracion de Environment (TEST/PRODUCTION)
- Revisar conectividad de red
- Verificar version de satcfdi compatible con el PAC
